# Signature-of-COVID19
Reproduction of the Viruses (2024) study "A T-Cell-Derived 3-Gene Signature Distinguishes SARS-CoV-2 from Common Respiratory Viruses", integrating DEG analysis, GSVA, CIBERSORTx, WGCNA, multi-model machine learning, RRA ranking, and cross-cohort validation across public transcriptomic datasets.
